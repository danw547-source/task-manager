# TaskFlow Dashboard

This project is a Vue 2 dashboard template adapted for task management use cases.

## Local Development

- Install dependencies: `npm install`
- Start dev server: `npm run serve`
- Build production assets: `npm run build`

## Notes

- The app is configured to run locally through Herd at `event-booking-api.test`.
- UI branding has been updated to TaskFlow.
- External promotional links from the original template docs were removed.

## Project Structure

- `public/` static HTML and app shell
- `src/` Vue application source
- `src/components/` reusable UI components
- `src/layout/` dashboard/starter layouts
- `src/pages/` route-level views
- `src/router/` application routes
